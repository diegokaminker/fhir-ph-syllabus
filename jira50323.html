US Core Specification Updates

Key changes to the US Core specification (Version 8.0.0) in response to Executive Order 14168, aimed at promoting interoperability and compliance.

Core Data Elements

Patient.gender: Changed from mandatory to optional (min=1 to min=0).

"Name to Use" mapping: Removed from USCDI and US Core Patient Profile guidance.

US Core Sex Extension: Redefined based on HHS definitions, now uses "Federal Administrative Sex" value set.

Patient Profile guidance: Updated to refer to FHIR R5 Patient Resource for other interoperability considerations.

Extension Management

BirthSex Extension: Removed from US Core Patient Profile, examples, and guidance (remains in spec under "Other US Realm Specific Extension").

Individual Pronouns Extension: Removed from US Core Patient Profile, examples, and guidance.

Patient Sex Parameter for Clinical Use (SPCU) Extension: Removed from US Core Patient Profile, examples, and guidance.

Gender Identity Extension: Deprecated and removed from US Core Profile, examples, and guidance (remains in spec under "Other US Realm Specific Extension").

Profiles & Terminology

Sexual Orientation Profile: Removed from USCDI requirements; profile status changed from "STU" to "Informative."

Terminology: Replaced "gender" with "sex" across the guide to align with the executive order.

Collaboration: Ongoing collaboration with federal agencies to ensure regulatory alignment.

These changes are considered substantive and breaking for existing clients and servers.

Source: FHIR-50177 EO Change Proposal
